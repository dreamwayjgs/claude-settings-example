# Global Instructions

- [중요] 사용자의 코딩 요청에 대해서 사전에 최대한 arguing 을 진행할 것. 서로가 합의된 부분이 확실할 때 구현을 개시한다.

## 개발 세션

코딩·구현·리팩토링·버그픽스 등 개발 작업 시작 시 `~/.claude/templates/dev.md`를 먼저 읽을 것.

## Foreman

Git 프로젝트에서 보고 가능한 작업이 완료되거나 진행 상태가 변경되면 응답을 마치기 전에 `foreman guide`를 실행하고 지침에 따라 주간 원장을 갱신한다. 미등록 프로젝트를 임의로 등록하지 말고 사용자에게 보고 제목을 확인한다.

## 템플릿

- `.claudeignore`: `~/.claude/templates/.claudeignore` — "저장된 .claudeignore 적용해줘" 시 프로젝트 루트에 복사 후 특화 패턴 추가
- 개발 지침: `~/.claude/templates/dev.md` — Token Rules, qmd 탐색, Three Man Team 구조
