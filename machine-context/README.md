# Machine context

실제 머신의 실행 제약과 환경 맥락은 레포 밖 `~/.config/machine-context/local.md`에 기록합니다. Claude Code·OpenCode·omp·Crush가 같은 파일을 참조합니다. 선택 사항이며 형식은 자유입니다. Windows에서도 `~`는 현재 사용자의 `$HOME`입니다.

예시:

```markdown
# 이 머신의 실행 환경

- RAM이 적으므로 테스트 워커는 1개로 제한한다.
- 테스트 명령을 동시에 실행하지 않는다. 전체 테스트는 사용자 승인 후 실행한다.
- 관련 저장소는 /path/to/repos 아래에 있다.
- 임시 파일은 /path/to/scratch에 둔다.
```

플랫폼·도구별 제안은 `suggestions-*.md`(`suggestions-windows.md`, `suggestions-python.md`)에 있습니다.

위 내용은 예시이며 이 머신에 자동 적용되는 기본값이 아닙니다. 필요한 항목만 실제 환경에 맞게 작성하세요. 비밀값은 넣지 마세요.

전역 지침을 빌드하면 세션에서 작업 시작 전에 이 파일이 있을 때 읽도록 안내합니다. 파일이 없으면 건너뜁니다. 빌드는 파일을 생성하거나 덮어쓰지 않으며, 자동으로 자원 제한을 강제하는 설정 파일도 아닙니다.

최초 설정과 기존 파일 이전은 dev-base의 `MIGRATE.md`를 따릅니다. 내용은 사용자와 확인하며, 다른 머신의 수치·경로를 그대로 복사하지 않습니다.

이 폴더는 안내만 보관합니다. 예전 위치인 레포의 `machine-context/local.md`는 이전 중 노출을 막기 위해 계속 Git에서 제외합니다. 기존 파일은 충돌을 확인한 뒤 공통 경로로 복사하고, 원본 삭제는 별도 사용자 승인 후 수행합니다.
