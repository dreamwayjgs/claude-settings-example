# 저사양 머신 제안

자원이 제한된 머신의 `~/.config/machine-context/local.md`에 넣을 만한 실행 규칙이다. 아래 내용은 예시이며 자동 적용되는 기본값이 아니다. 실제 코어 수와 메모리 여유를 확인하고 소유자와 합의한 항목만 옮긴다.

## local.md 예시

```markdown
## 자원 사용

- 테스트·빌드·타입체크의 동시 워커 합계는 논리 코어 수에서 2를 뺀 값을 상한으로 한다. 1~2코어 머신의 상한은 1이다. CPU 수 기반 자동 병렬도에 맡기지 않고 워커 수를 명시한다.
- 여러 에이전트나 프로세스가 동시에 작업할 때는 워커 수와 메모리 사용량을 합산해 판단한다. 코어 수에 따른 상한은 메모리 안전을 보장하지 않으므로 가용 메모리와 작업 특성에 맞춰 병렬도를 낮춘다.
- 워커 상한을 초과하거나 대규모 전체 테스트를 실행하기 전에는 사용자 승인을 받는다. 중단된 테스트는 통과로 취급하지 않는다.
- 자원 부족 징후가 있으면 추가 실행을 멈추고 확인한다. 다른 작업의 프로세스를 임의 종료하거나 캐시·로그를 대량 삭제하지 않는다.
```

## 머신별 보완

- 실제 RAM, OOM 이력, 필요한 메모리 기반 워커 상한은 해당 머신의 `local.md`에 기록한다. 다른 머신의 수치·경로를 그대로 복사하지 않는다.
- 검색·파일 읽기 같은 가벼운 작업까지 무조건 순차 실행할 필요는 없다. 무거운 작업의 병렬도와 구분한다.
